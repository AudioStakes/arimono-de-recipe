# 依頼文を送ってレシピを読む

## ゴール

材料と要望から作ったレシピ依頼文をアプリ内AIへ送り、その回答を読みやすいMarkdownで受け取る。普段使っているAIを選ぶ利用者には、同じ依頼文をコピーする操作を残す。

## 画面と操作

- 主操作は送信アイコン付きの「AIへ送信」。副操作はコピーアイコン付きの「依頼文をコピー」。アイコンだけに頼らず、短い表示とアクセシブルな名前を付ける。
- desktopは材料とリクエストの2カラム、mobileは1カラムにする。回答は入力の下に置き、両方の幅で送信とコピーを固定操作から使えるようにする。
- 回答カードは「AIの回答」とページ内の「依頼文を見る」で構成する。入力を促す前置きや送信・コピーの重複操作は置かない。送る依頼文は必要なときだけ開ける。
- 送信開始時は待機状態を示し、連打による重複送信を防ぐ。コピーは待機中も利用できる。
- mobileでは送信開始時に回答位置へ移動する。回答到着時には操作中のfocusやscrollを奪わない。
- 失敗時は理由と再試行を示し、コピーを残す。入力変更時は古い通信と回答を無効にする。
- 通常の依頼文プレビューはページ内で開く。固定フッターには送信・コピーと「Created by AudioStakes」「プライバシー」を配置し、送信先表示やプレビューへの動線は置かない。
- AI選択と利用状況の詳細はプライバシーダイアログ内の任意設定に置く。利用不可の理由だけを回答欄に表示し、空の通知領域は初期表示から支援技術へ公開する。送信先は設定と送信ボタンの説明・titleで確認できる。設定変更だけでは送信しない。
- コピー失敗時はdesktopではページ内の依頼文を開いて選択し、その位置へ移動する。mobileでは本文を選択できる代替sheetを開く。送信時・設定ダイアログを開くときはsheet・inert・scroll lockを解除する。入力エラー時は回答へ移動せず、問題の入力を案内する。
- 材料なし・分量不足の説明は該当入力の近くに表示する。focusした入力とエラーがmobileの固定操作に隠れないようにする。

## 現行の入力と依頼文

材料の使い方・量に加え、任意の入力は「人数・分量」「調理方法・調理器具」「その他の要望」の3項目に限定する。各項目だけで役割が伝わるため、全体をまとめる「今日のリクエスト」の見出しは表示しない。旧intent・料理名・品数・役割・調理時間・方向性・NGのstateや候補は互換のため残せるが、読取モデル・依頼文・条件チップへ含めない。

料理名、品数、調理時間、食材の制約、保存方法などは自由記入のままAIへ伝える。品数の希望がなければ1品を既定とし、希望がある場合はその他の要望を尊重する。明示的に求められた保存方法や栄養の説明などを一律の省略ルールで抑止しない。家にない主材料を追加しない原則は維持する。

## 削除する機能

3候補生成、候補一覧・詳細・調理タブ、候補用のrequest／response schema・API処理・状態を削除する。入力の候補値、材料の使い方・分量の検証、依頼文生成は維持する。

## 実装順と完了条件

1. 候補経路を除き、全文送信へ一本化する。完了条件は候補のruntime参照がなく、コピーと送信が同じ `buildPrompt(data)` を使うこと。
2. 送信・回答中心の画面と安全なMarkdown表示を実装する。完了条件は見出し・箇条書き・強調・表が読みやすく、raw HTML・危険URL・外部画像を実行しないこと。
3. API・表示の安全性、操作・視認性、回帰テストを独立レビューし、指摘を修正する。旧候補専用テストは機能廃止に合わせて整理し、入力・コピー・上限・通信の回帰は新経路へ移す。必須hook・AGENTS・CONTEXT・architecture・UX matrixも同期し、送信先・保存禁止・依頼文の原本に関するguardを維持する。raw HTML・危険URL・Markdown画像・HTML画像を与えて、実行と第三者通信が0件であることを確認する。
4. 全checkと複数ブラウザー・画面幅で操作を確認し、画面・録画・READMEを更新する。PRの必須CIを確認してから、今回の所有者の明示依頼に従ってマージする。

## 維持する境界

このフロー導入時の送信先は同一オリジン `/api/recipe` とCloudflare Workers AIに限定した。その後、[ADR 0016](../adr/0016-add-free-model-selection-and-durable-usage-limits.md)が同じ入口での固定モデル・Groq選択とD1利用制限集計を承認した。モデル情報のGETには入力を含めず、明示POSTだけが依頼文全文を送る。依頼文を省略して送らず、文字数・UTF-8本文サイズ・30秒timeoutを維持する。入力・回答の保存とログインは追加しない。解析は[ADR 0015](../adr/0015-add-cloudflare-web-analytics-and-privacy-dialog.md)の本番beaconだけに限る。AIの回答を材料・NG条件の検証済み結果として扱わない。
