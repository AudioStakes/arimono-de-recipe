# 入力とAIの詳しい使い方

## 入力とAI候補の制約

買い足しなしが基本です。入力した材料のほか、塩・油・しょうゆ・だし等の基本調味料を家にあると仮定します。持っていないものは「NG食材・調味料」に指定してください。現在の画面には買い足しを許可する操作はありません。

AI候補は短い参考情報です。材料は最大6項目、手順は最大3項目で、調味料の具体的な分量や加熱条件が十分に揃わない場合があります。NG指定は材料・手順・料理名・推薦理由・味の調整で文字列を照合し、「しょうゆ／醤油」「みそ／味噌」「こしょう／胡椒」「だし／出汁」の表記も対応します。それ以外の別名・派生原料・交差接触の判定には対応していません。「にんにく不使用」のようにNGの文字を含む否定表現も保守的に拒否します。アレルギー対応や調理の安全性を保証するものではありません。実際に作る前に材料と手順を確認してください。

| AI候補へ送る項目 | 上限 |
| --- | ---: |
| 家にある食材・材料 | 12件 |
| うち「必ず使う・使い切る」と指定する材料の合計 | 6件 |
| 料理の要望（方向性・役割・作りたい料理・合わせる料理の合計） | 5件 |
| 調理方法・調理器具 | 8件 |
| NG食材・調味料 | 8件 |
| 各材料名・各要望・分量 | 80文字 |
| 今回やりたいこと・品数の説明と補足の合計 | 180文字 |

人数は80文字、時間は40文字までです。選択した「今回やりたいこと」と「作りたい品数」は補足と一緒に送り、合計180文字までです。全体にも送信サイズの上限があります。上限を超えた入力は一部を黙って省くことなく、画面で修正を案内します。**依頼文コピーにはAI候補用の件数制限を適用しません。** 30秒で応答を受け取れない場合も、コピーを続けて利用できます。

### 依頼文全文を送る場合

候補用の件数制限は適用しません。依頼文は12,000文字（JavaScriptの文字列長）、`{"prompt": "…"}` 全体はUTF-8で32,000バイトまでです。日本語やJSONのエスケープによって、文字数上限より先に本文サイズ上限へ達する場合があります。超過時は省略して送らず、依頼文全文のコピーを残します。こちらも通信・応答本文の読み取りを30秒で中断します。

全文送信の回答は自由文です。候補用の材料・必須材料・NGの自動照合を行いません。既存の応答トークン上限により回答が途中で終わる場合もあります。材料・分量・NG条件・手順は自分で確認してください。実モデルが入力条件を守ることや、アレルギー・調理の安全性を保証するものではありません。

## 入力内容の扱い

- 入力・依頼文生成・コピーはブラウザ内で行います。
- **「今日の候補を見る」または「この依頼文をAIへ送信」を押した時**に、候補条件または依頼文全文を同じサイトの `/api/recipe` に送り、Cloudflare Workers AIで処理します。入力・依頼文の確認・コピーだけでは外部AIへ自動送信しません。
- アプリのコードには入力の永続保存・ログ出力・アクセス解析・ログイン機能はありません。再読み込みすると入力は失われます。
- ホスティング事業者や、自分で貼り付けるAIサービスによるデータの取扱いは各サービスの方針に従います。自由記述には氏名などの個人情報を入れないでください。

公開運用時の呼び出し制限・費用・バインディング設定については[公開手順](deployment.md)を確認してください。
