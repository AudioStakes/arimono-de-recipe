# 入力とAIの詳しい使い方

## AIへ送る依頼文

「AIへ送信」は、画面で確認・コピーできるレシピ依頼文の全文を送ります。候補選択の工程はなく、AIの回答をそのままMarkdownの見出し・材料リスト・手順として読みます。普段使うAIへ依頼したい場合は「依頼文をコピー」を使ってください。入力の候補値は、材料や要望を追加するための補助です。

買い足しなしが基本です。依頼文は入力した材料を使うよう依頼し、NG食材・調味料などの要望を反映します。未指定の項目と、その項目だけに必要なルールは依頼文へ含めません。料理名・調理時間・使えない食材や調味料などは「その他の要望」へ記入してください。

「その他の要望」では、品数や保存方法などの希望も伝えられます。品数の希望がなければ1品を依頼します。利用するAIの変更は、固定フッターの「プライバシー」にある「AIの設定」から行えます。通常は初期設定のAIをそのまま使えます。

| 項目 | 上限 |
| --- | ---: |
| 依頼文 | 12,000文字（JavaScriptの文字列長） |
| promptと選択モデルを含むJSON全体 | UTF-8で32,000バイト |
| AI回答 | 20,000文字 |
| 通信・応答本文の読み取り | 30秒 |

日本語やJSONのエスケープによって、文字数より先に本文サイズの上限へ達する場合があります。上限を超えた依頼文は省略して送らず、全文コピーを残します。旧料理候補用の件数制限は適用しません。「使い切る」を選んだ材料では量の入力が必要です。

送信中もコピーできます。入力を変更すると古い通信と回答を無効にします。30秒で中断しても、サーバーでの推論停止や利用量の取消を保証するものではありません。

## 回答の見方

見出し・段落・箇条書き・強調・コード・表を表示します。raw HTMLと画像は表示せず、絶対URLのHTTP(S)リンクだけを別タブで開けます。回答を表示するだけで外部画像を読み込みません。

極端に大きい表や複雑な回答は、画面の負荷を抑えるため表示しない場合があります。再送信するか、依頼文をコピーして普段使うAIへ相談できます。

回答は自由文で、材料・必須材料・NG条件の自動照合は行いません。別名・派生原料・交差接触や調理の安全性も判定しません。**調理前に材料・分量・NG食材・加熱条件を確認してください。** 出力トークン上限のため回答が途中で終わる場合もあります。

## 入力内容の扱い

- 入力・依頼文生成・コピーはブラウザ内で行います。
- **「AIへ送信」を押した時だけ**、依頼文全文を同じサイトの `/api/recipe` に送り、選択したCloudflare Workers AIまたはGroqで処理します。入力・依頼文の確認・コピーだけでは自動送信しません。利用できるモデルの確認には入力内容を含めません。
- アプリのコードには入力の永続保存・ログ出力・ログイン機能はありません。再読み込みすると入力は失われます。
- 同じ接続元は1分3回・UTC日10回、全体はUTC日100回を上限とします。使用量の上限も別にあり、停止中もコピーはできます。日次枠は日本時間9時に切り替わります。
- 接続元を日替わりHMACで仮名化したbucketと回数・使用量だけをD1へ保存し、期限切れの集計は次のAI送信時に削除します。元のIP・食材・依頼文・回答はこの集計に保存しません。同じネットワークで枠を共有する場合があり、厳密な一人単位の識別ではありません。
- Cloudflareは標準推論を学習利用しないと説明しています。Groqは障害・不正利用の調査で入力・出力を通常最大30日保持する場合があります（法令でより長い保持が必要な場合を除きます）。[Cloudflareのデータ方針](https://developers.cloudflare.com/workers-ai/platform/data-usage/)、[Groqのデータ方針](https://console.groq.com/docs/your-data)
- ホスティング事業者や、自分で貼り付けるAIサービスによるデータの取扱いは各サービスの方針に従います。自由記述には氏名などの個人情報を入れないでください。

## アクセス解析とプライバシー

フッターの「プライバシー」から、アプリ内の説明を開けます。作者のXへ移動するリンクも同じ場所にあります。

本番サイトは改善のためCloudflare Web Analyticsを利用し、閲覧ページ・参照元・端末・ブラウザ・表示速度などを集計します。食材・要望・依頼文・AI回答を解析へ送る独自イベントはありません。解析にCookieやlocalStorage、個人を識別するフィンガープリントを使いません。通信に伴うIPアドレスはCloudflareで処理されます。[Cloudflareのデータ説明](https://developers.cloudflare.com/web-analytics/data-metrics/core-web-vitals/#information-collected)

ローカル・Previewでは解析を読み込みません。広告ブロッカーなどで解析を読み込めなくても、材料入力・AI送信・依頼文コピーを利用できます。

公開運用時の呼び出し制限・費用・バインディング設定については[公開手順](deployment.md)を確認してください。
